# NästaStopp Suite

Independent development copy of HussamEl/S20Ultra, branch claude/nasta-stopp-android-app-soeru7, source commit 901da16b0dc7e7da397fdd67ac2520fe55510cb2 (Nästa Stopp 1.46).

The original repository is read-only for this project. All development belongs to HussamEl/NastaStopp-Suite.

Requested products: separate taxi/Färdtjänst/Sjukresor and truck applications using the original design and tablet mode, plus a browser companion for explicitly enabled work-device location sharing. Android, iPad and browser delivery require platform-specific implementation; the upstream APK is Android-only.

Original source and licenses are retained. Upstream release workflows are archived under docs/upstream-workflows so importing this project cannot run the old release process. No signing keys or user login credentials are included.
